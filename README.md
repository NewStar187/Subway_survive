# Subway Survive

한국 지하철에서 AI 승객 사이에 섞인 다른 플레이어를 찾아내는 1인칭 웹 게임.

**플레이: https://newstar187.github.io/Subway_survive/**

## 같이 하기

1. 한 명이 닉네임을 적고 **방 만들기**를 누른다. 화면 왼쪽에 방 코드가 뜬다.
2. 나머지는 같은 주소로 들어가 방 코드를 적고 **참여**를 누른다.
3. 방장이 **게임 시작**을 누르면 겉모습과 위치가 섞이고, 문이 열리면 열차에 탄다.

- 방장은 시작 전에 방 패널에서 칸 수(2~8칸)를 정한다. 추천은 참가 인원 + 1칸이다. 혼자 할 때는 첫 화면에서 고른다.
- 방장의 브라우저가 승객과 열차를 계산한다. 방장이 페이지를 닫으면 방이 끝난다.
- 방 패널의 버튼은 Esc로 마우스를 푼 뒤 누른다. 방장은 강퇴와 로비 복귀를 할 수 있고, 누구나 관전으로 바꿀 수 있다.
- 접속 중개는 PeerJS 공개 서버를 쓴다. 학교·회사 네트워크처럼 P2P가 막힌 곳에서는 접속이 안 될 수 있다.

## 규칙

- 문이 닫힐 때마다 라운드가 시작되고, 플레이어마다 미션이 하나씩 주어진다. 실패하면 라운드 수 × 1.5초 동안 위치가 드러난다.
- 열차가 출발하면 다음 역에서 폐쇄될 칸이 안내된다. 번호가 가장 작은 칸(꼬리칸)부터 닫히며, 열차가 서는 순간 그 칸에 남아 있으면 탈락한다. 승객들은 안내를 듣고 앞 칸으로 옮겨 간다.
- 폐쇄된 칸은 통로가 막히고 문이 열리지 않으며, 열차가 떠날 때 역에 남는다.
- 마지막 한 칸만 남으면 승객은 내리기만 하고, 칼과 총알이 주기적으로 다시 생긴다.
- 정차 중에는 누구나 내렸다 탈 수 있지만, 문이 닫힐 때 승강장에 있으면 탈락한다.

## 조작

WASD 이동 · Shift 달리기 · E 앉기/손잡이/줍기/구매 · 클릭 공격/마시기/휴대폰 보기 · 1~5와 휠로 물건 바꾸기 · H 휘파람 · G 그래픽 품질

## 구조

`index.html` 한 파일로 동작한다. `src/`의 조각을 `python3 build.py`로 합쳐서 만든다. 배포는 `gh-pages` 브랜치를 쓴다.

| 파일 | 내용 |
| --- | --- |
| `src/page.html` | 화면 틀, 입력, 프레임 루프 |
| `src/people_core.js` | 승객 모델과 동작, 손에 드는 물건 |
| `src/env.js` | 역과 열차, 재질, 조명, 후처리 |
| `src/npc.js` | 승객 행동과 그리기 |
| `src/net.js` | 방, 접속, 동기화 |
| `src/game.js` | 플레이어, 미션, 무기 |
| `src/vendor/peerjs.min.js` | PeerJS 1.5.4 (MIT) |
